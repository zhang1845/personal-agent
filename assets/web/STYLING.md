# 前端样式维护

当前采用用户在 2026-10-27 提供的 **Ui — clinical blueprint on frosted paper** 浅色规格。参考用于现有工作台的视觉规范，技术栈继续使用原生 HTML/CSS/JavaScript 与本地 Bulma 1.0.4。

## 文件职责

1. `vendor/bulma-1.0.4.min.css` 保留原样，提供表单、按钮和基础布局。
2. `brand.css` 定义颜色、字体、圆角、控件尺寸和 Bulma 映射。替换主题在这里修改，不新增叠加皮肤。
3. `styles.css` 定义工作台网格、导航、月历、列表、助手和响应式布局。

原始规格保存在 `design/ui-style-reference.md`，落地说明见 `DESIGN-REFERENCES.md`。

## 主题约定

- 画布 `#f5f5f5`、侧栏 `#fafafa`、内容 `#ffffff`；正文 `#0a0a0a`，辅助文字 `#737373`，边框 `#e5e5e5`。界面采用黑白灰，选中项通过明暗和字重区分。
- 主按钮黑底白字；次按钮浅灰底；轮廓按钮用细灰边。红色 `#e7000b` 只表示错误和破坏性操作。原始参考的颜色表与后文对此有冲突，本实现遵循组件和 Do/Don't 中的“红色只用于错误/删除”。
- 控件、标签、选中导航使用 18px 圆角，面板和弹窗使用 24px。月历内部保持相接的数据网格，外沿使用圆角，日期选择和事件入口使用 18px 圆角。
- 面板使用 20px 内边距、1px 细边框和轻投影；列表仍以细分隔线组织，不逐条增加卡片。概况数字没有独立卡片外壳。
- Geist 可变字体随项目本地提供，不连接外部字体服务；中文使用 PingFang SC / Microsoft YaHei / 系统回退。字体许可和来源校验见 vendor/。启用 ss01 与 cv11，字重使用 400/500/600。
- 正文和表单 14px，辅助说明 13–14px，日期/计数等短标签 12px。普通页标题 36px，总览标题 48px，手机标题 28px。大标题收紧字距，正文保持自然字距。
- 常规控件高 40px，紧凑控件高 32px；输入静态浅灰填充，聚焦变为白底细灰环。图标操作保留可见的键盘焦点，禁用状态通过原生 disabled 管理。

## 页面与响应式

主内容最大 1280px；侧栏 176px，中等窗口 152px。总览保留当天日程主区，以及下一场安排、紧凑待办和空闲查询侧栏。日历保留月/周/日、所选日期详情和空闲查询。1100px 以下内容侧栏向下排列；760px 以下导航排成四列、两行，表单与内容堆叠。

助手继续使用原生 dialog 模态抽屉，桌面右侧 400px，手机为带 24px 圆角的底部面板。showModal、焦点返回、Escape 和草案确认逻辑不改。资料导入、重复日程、通知、CalDAV 和 API 表单复用同一控件体系。

不添加渐变、模糊玻璃、装饰图片、演示数据、动画或主题切换。只有一处 `[hidden]` important，确保隐藏的业务控件不被布局样式显示。

## 检查方式

使用项目 `.venv` 启动服务；功能验收在隔离 data-dir 完成。覆盖 1440/1024/768/390/320 宽度、七个页面、日程和待办增改、资料预览、助手草案及自动化控件。真实账号与原有个人数据不填入测试内容。

## 页面文案

正常页面只显示功能、必要状态和下一步操作，不展示 SDK、依赖版本、内部字段、请求编号或运行方式。接口格式与连接要求放进原生 details 帮助，默认收起；API 地址、Key、模型名称及日程时区等必要设置仍保留。

确认卡片使用实际日程或待办的名称与时间，日程详情未读到或已变化时不允许确认；内部 ID、版本校验和请求去重继续在后台保留。错误说明如何恢复，未知结果提示先核对，不能隐藏失败或声称操作成功。资料引用保留存储的版本和摘录，界面不显示数据库版本号。不要改写用户已保存的资料、想法或历史对话。

## 评测与反馈

新增评测与反馈页沿用本地 Bulma 与当前主题。反馈和用例采用列表、折叠详情和细分隔线，宽屏并排，窄窗口堆叠；指标用可横向滚动的表格显示。手机导航长标签允许换行。反馈、引用和用例编辑使用原生 dialog，所有动态文本通过 textContent 创建。无示例或样本时显示空状态，百分比无分母时显示暂无样本。8页已检查 1440/1024/768/390/320 宽度。
